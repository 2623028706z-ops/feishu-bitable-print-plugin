# 打印筛选与 T+2 设计

## 目标

在花众销售订单打印插件中，允许用户按客户、花束、出货日期和数量筛选打印范围，并支持自定义基准日 T 的 `T+n` 出货日期模式。

## 方案

- 飞书读取逻辑保持不变：先读取当前视图或已勾选记录，再在插件内筛选，不回写 Base。
- 客户、品类和花束使用多选；空选择表示不过滤。
- 出货日期提供指定日期、日期范围、T+n 三种模式。T 为本地日期输入，n 为非负整数。
- 数量提供按订单数量和自定义数量两种模式。自定义数量只影响标签副本数；加工单仍使用订单数量。
- 标签与加工单共用筛选结果；无匹配时显示空状态并禁用打印按钮。
- 销售订单表的 `养护说明` 字段可在标签内容中独立开启，空字段不渲染占位。

## 验收

- 客户/花束多选可组合筛选。
- T+2 在基准日为 2026-08-23 时只匹配 2026-08-25 出货订单。
- 标签数量可从销售数量切换为自定义数量。
- 加工单只展示筛选后的订单，且保留配方展开。
