# 花众共享打印模板重做设计（方案 B）

## 目标

使用成熟的 React 开源组件重做飞书多维表格打印插件。保留已经接通的订单字段、花束编码、品类兼容、成品配方和加工单数据链路，重做筛选、标签编辑、A4 排版、模板管理与打印任务。

模板只在当前飞书 Base 内共享。同一 Base 的成员可以使用共享模板；只有对模板配置表有编辑权限的成员可以修改。模板不跨 Base、公司或租户共享，不新增服务器、账号、App Secret 或 tenant token。

## 技术底座

- React 18 + Vite：保持现有项目框架。
- `react-konva` + `konva`：标签模板的拖动、缩放、选择和边界控制，MIT 许可。
- `react-to-print`：隔离标签打印文档和 A4 加工单文档，MIT 许可。
- `react-select`：客户、品类和花束的搜索多选，MIT 许可。
- `JsBarcode`：继续生成 CODE128 条码，MIT 许可。
- 飞书多维表格 JS SDK：读取订单和在当前 Base 中持久化共享模板。

不接入 Vue/jQuery 版 hiprint，不引入完整网页搭建器，也不做模板市场、跨企业同步或任意 HTML 脚本模板。

## 必须保留的业务规则

- 数据读取优先级：已勾选记录 → 当前选中记录 → 当前视图记录。
- 默认筛选真实出货日期为今天，不加载历史样例订单。
- 客户、品类和花束支持多选；同一维度内为 OR，不同维度间为 AND。
- 品类继续兼容单选、多选、关联、查找、公式包装值和带后缀字段名。
- `T+n` 只改变标签显示日期，不改变订单筛选日期。
- 条码图形与编码文字只能读取飞书“花束编码”字段 `productCode`，禁止使用订单号或自动生成值兜底。
- 标签纸与 A4 加工单使用独立模板、独立打印文档和独立 `@page` 规则。
- 加工单继续显示真实客户与真实出货日期。

## 标签模板

标签模板只包含以下六类业务组件：

- 花束名称
- CODE128 条码
- 花束编码文字
- 标签日期
- 客户名称
- 养护说明

标签不读取、不计算、不显示 BOM 配方、花材、单束用量、总支数或销售数量。订单没有关联成品配方时，不影响标签预览与打印；“未关联成品配方”只允许出现在加工单模式。

标签编辑器使用 Konva，只渲染一张真实订单样例。组件支持拖动、缩放、显隐、字号、粗细和对齐，且不能越出标签边界。画布使用像素交互，但模板保存毫米坐标；打印时不用 Canvas 截图，而用相同毫米坐标生成清晰的 DOM/SVG。

标签模板可设置：模板名称、标签宽高、行列、横纵间距、页边距、字段位置与尺寸、字段显隐、字体、字号、粗细、对齐和标签日期偏移。第一阶段不做旋转、自由图形、图片上传、复杂图层树或脚本字段。

## A4 加工单模板

A4 使用结构化排版编辑器，不使用标签 Canvas。用户可以编辑：

- 模板名称和加工单标题名称。
- A4 横向或纵向、页边距、页眉和页脚。
- 标题、客户、真实出货日期、订单统计等信息块的显示、顺序、字体、字号、粗细和对齐。
- BOM 表格列的显示、顺序、列名、列宽和对齐。
- 表头与表体字体、字号、粗细、行高、内边距、背景色和文字色。
- 外边框、内横线、内竖线的显隐、粗细、线型和颜色。
- 分页重复表头、分页留白和页码显示。
- 备注区的显示、名称和样式。

A4 编辑器不允许任意 JavaScript、任意 HTML、删除核心数据绑定或把 BOM 放入标签。核心数据列至少保留花束、花材、加工扎数、单束用量、总支数和备注；可隐藏非关键列，但保存时必须通过模板校验。

加工单 BOM 保持现有解析回退顺序：销售订单直连配方 → 花束关联的成品汇总表 → 按花束名称查询成品汇总表 → 当前订单记录的配方字段。

## 模板共享与权限

当前 Base 中使用专用数据表“打印模板配置”存放共享模板。建议字段：

| 字段 | 用途 |
| --- | --- |
| 模板ID | 稳定唯一标识 |
| 模板名称 | 用户可编辑名称 |
| 模板类型 | 标签 / A4加工单 |
| 纸张规格 | 标签尺寸或 A4 方向摘要 |
| 模板JSON | 经过校验的版本化模板数据 |
| 版本号 | 乐观并发控制 |
| 是否默认 | 当前类型的默认模板 |
| 状态 | 启用 / 停用 |
| 更新人 | 最后修改人 |
| 更新时间 | 最后修改时间 |

模板管理支持新建、复制、重命名、保存、删除、设为默认和恢复系统默认。删除共享模板必须二次确认；默认模板不能直接删除，需先设置另一模板为默认。

所有成员可以读取并使用模板。只有对“打印模板配置”表有编辑权限的成员可以保存、删除或设为默认；SDK 返回权限错误时，界面保持只读并明确提示，不尝试绕过飞书权限。

保存采用乐观版本检查：若远端版本已经变化，禁止静默覆盖，提示用户重新载入或复制为新模板。浏览器只缓存最近使用的模板和未提交草稿；共享版本始终以 Base 配置表为准。

若配置表不存在，具备建表权限的成员可运行一次初始化；没有权限的成员只能使用内置默认模板，并看到简短的管理员初始化提示。初始化不得修改订单表结构。

## 筛选、数量和重置

客户、品类和花束使用 `react-select` 搜索多选，支持输入过滤、已选数量和清空。出货日期默认今天。

标签数量支持“按销售数量”和“每单固定张数”。固定张数范围为 1–500，总标签数最多 5000。编辑画布始终一张，普通预览最多渲染 100 张；超过时显示“仅预览前 100 张”。输入 `10000` 或读取到旧的异常记忆时自动纠正，不允许创建一万个 React 节点、Canvas 或条码 SVG。

界面只保留两个明确重置入口：

- 恢复默认排版：只恢复当前模板的排版与样式。
- 清空筛选：只清空客户、品类、花束，日期恢复今天，数量恢复按销售数量。

## 界面结构

保持简单的左右布局：

- 左侧控制区：模式、模板选择、搜索筛选、日期、数量、当前模板的核心设置、两个重置按钮和打印。
- 右侧工作区：标签模式显示单张编辑画布与有限打印预览；加工单模式显示结构化 A4 编辑/预览。

打印是唯一高亮主按钮。模板管理放在紧凑菜单中，不铺成大量按钮。属性设置按当前模式和当前选中组件渐进显示；窄侧栏下使用抽屉，不把画布压缩到不可用。

## 打印流程

`react-to-print` 分别打印两个隐藏文档：

- 标签文档：自定义毫米纸张、行列、间距、页边距，字段使用毫米绝对定位。
- 加工单文档：A4 横向或纵向，根据模板分页，跨页重复表头并生成正确页码。

打印前校验模板结构、纸张尺寸、数量上限和花束编码。浏览器只打开系统打印对话框，不承诺绕过打印机驱动、静默打印或自动修改驱动缩放；界面提示使用实际尺寸/100% 缩放。

## 架构边界

建议拆分为：

- `src/domain/print`：订单筛选、数量限制、标签日期和加工单聚合。
- `src/domain/templates`：标签/A4 模板类型、默认值、校验、迁移和毫米几何。
- `src/infrastructure/feishu`：订单读取、配方解析、共享模板存储和权限错误映射。
- `src/features/filters`：搜索多选与日期/数量控件。
- `src/features/label-editor`：Konva 标签编辑器。
- `src/features/work-order-editor`：A4 结构化样式编辑器。
- `src/features/print`：标签与 A4 的独立打印文档。
- `src/features/templates`：共享模板列表与管理动作。

现有飞书适配器先保留行为并加缓存，再按边界拆分；不做大爆炸重写。

## 迁移顺序

1. 加入数量上限、预览截断和旧记忆迁移，先解决 `10000` 卡顿。
2. 建立版本化模板领域模型、默认模板和校验测试。
3. 拆分筛选与打印文档，使用 `react-select` 和 `react-to-print`。
4. 接入 Konva 标签编辑器，验证毫米坐标与条码一致性。
5. 实现 A4 结构化编辑器和分页打印。
6. 实现 Base 配置表共享、权限、版本冲突和模板管理。
7. 浏览器、飞书内嵌、标签 PDF 与 A4 PDF 验收后再替换线上版本。

## 验收标准

- 标签六种组件可以拖动和缩放，打印毫米位置与画布保存值一致。
- 标签条码和编码文字都等于真实花束编码。
- 标签完全不读取、打印或提示 BOM；无配方订单仍可打印标签。
- A4 可编辑模板名称、标题、纸张方向、页边距、字体、字号、粗细、对齐、边框、列名、列宽、列顺序、页眉页脚和分页。
- A4 继续显示真实客户、真实出货日期和正确 BOM 配方。
- 客户、品类和花束支持搜索多选，组合筛选正确。
- 输入 `10000` 不会卡死；旧异常记忆刷新后恢复到安全值。
- 标签预览最多 100 张，总量超过 5000 时禁止打印并提示缩小范围。
- 同一 Base 成员可以读取共享模板；只有配置表编辑者能修改。
- 并发修改不会静默覆盖，删除/恢复默认有明确确认。
- 标签与 A4 模板、纸张和打印规则完全隔离。
- 单元测试、构建、浏览器交互、飞书内嵌和两类 PDF 验收通过。
