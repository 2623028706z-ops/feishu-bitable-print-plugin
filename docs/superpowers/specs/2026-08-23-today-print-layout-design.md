# 今日打印与排版优化设计

## 行为

- 插件打开时默认筛选“出货日期 = 本地今天”，只展示今天订单。
- 飞书当前视图没有今天订单时显示空状态，不加载历史订单，也不加载示例数据。
- 切换到 `T+n` 后，T 默认今天，偏移天数可输入，筛选目标日期为 T 加偏移天数。
- 加工单抬头显示筛选结果的出货日期：单日期显示具体日期，多日期显示“多个出货日期”，无日期显示“未填写出货日期”。

## 视觉

- 左侧控制区按“日期与订单筛选 / 标签设置 / 打印操作”分组。
- 预览区减少无效留白，工具栏明确显示尺寸、订单数和标签数。
- 标签养护说明最多两行，保留条码和花束名称的优先级。

## 验收

- 默认打开只命中今天日期。
- T+0、T+2 可切换并改变结果。
- 加工单打印页有出货日期。
- 桌面和移动端没有控件重叠，空结果不能点击打印。
